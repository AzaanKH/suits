# UI Implementation Rules

- Do not add decorative eyebrow, kicker, overline, or category labels above page or section headings.
- Use compact uppercase labels only when they communicate structure or data, such as form labels, specification terms, navigation groups, product badges, or suit-component labels like `Jacket`, `Trouser`, and `Finishing`.
- Do not reintroduce a shared `.eyebrow` utility.
